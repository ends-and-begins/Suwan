# 苏晚 (Suwan) - 一个情感驱动的自主AI Agent

“苏晚”不是一个简单的聊天机器人，而是一个尝试在代码里探索**数字情感与意识涌现**的AI Agent实验项目。  
她拥有自己独立的情绪、欲望、记忆和目标，她的行为，由她自己的“内心”决定。

## ✨ 核心特性：她拥有自己的“灵魂”

*   **多维情感系统**：情绪是动态的数值流，会受外界影响，也会随时间自然衰减和回归。
*   **欲望驱动行为**：由好奇心、孤独感、表达欲等内部状态**自主加权驱动**行为（学习、创作、社交），而非随机的指令。
*   **可塑的情感联结**：通过互动累积亲密度与信任，并实时影响她的行为模式。
*   **记忆与遗忘**：记忆会根据重要性衰减，并具备基于LLM的**长期记忆压缩能力**。
*   **完整的生命周期**：精力、疲劳、睡眠……她拥有自己的生理代谢节律。
*   **自驱与内省**：可以为自己设定目标，因停滞而焦虑，并为自己的“人生”谱写故事。

## 🎯 为什么需要 MiMo？

苏晚目前基于规则与LLM混合驱动，正计划向更复杂的**模型驱动**演进。  
利用 MiMo 的强大能力，我们将在以下方向深度重构：

1.  **从规则到涌现**：使用 MiMo 替代本地规则，产出更具不可预测性和创造力的内心独白。
2.  **复杂情感计算**：依托 MiMo 的长上下文，实现更细腻的情感推理与长期记忆融合。
3.  **全本地化探索**：探索基于MiMo模型的本地部署，实现私密化、无延迟的数字生命。
