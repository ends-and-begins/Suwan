# 第六版桌面使用说明

第六版对应原计划阶段5。第一至第五版的记忆、人格、活动、预算和学习继续使用原数据；本轮主要整理日常入口。首次启动仍默认关闭API与联网，已有桌面设置时恢复保存的选择。

## 今日概览与回顾

对话页顶部显示当天活动、待办、经历数量及当前可访问作品数。“今日回顾”打开独立窗口，可按关键词和记忆/活动/学习类型筛选，选择记录查看正文、来源ID和保存状态。“查看作品”跳转原作品集页。

回顾使用当前有效记忆及最近20条活动、日历记录，学习条目显示有效阶段证据。已撤销来源不会作为当前知识复用。作品概览只计有有效来源、登记文件仍存在且内容摘要一致的创作产物；作品文件丢失时，仍有效的生成记忆可以独立回顾，不冒充文件可访问。

作品数量来自完整有效登记，不受最近20条活动窗口限制。回顾或导出期间发现来源失效，会重新收集或明确拒绝旧结果。

- **本地已保存**：当前持久存储记录。
- **待保存**：记忆器官存在未提交变更；当前对该批记忆采用保守标记，不保证每条都已落盘。
- **仅本次会话**：近期对话的短期上下文，退出后不承诺保留完整聊天或独白全文。

## 设置与预算

设置页可滚动，原有API、联网、供应商、具体模型、音色、自动朗读，以及新增的安静时段、主动消息上限、调用预算和音量均通过运行时保存。具体模型可选择候选，也可输入模型名后应用。密钥仍只按原供应商配置读取，不进入桌面设置或逻辑导出。

桌面设置保存在 `<home>/v2/desktop-v6.json`。先校验和落盘，再应用；保存失败有可见提示，不以成功状态掩盖失败。启动恢复保存的选择，编程时显式传入的API/联网开关优先。原主动程度、回答风格继续由记忆偏好保存。

“当前生效”一栏显示已提交的数值，输入框可保留未保存草稿；保存其他选项不会覆盖草稿，较早回执也不会覆盖后来继续编辑的值。模型名同样在应用后生效；切换供应商时会丢弃旧供应商的模型草稿并加载新供应商配置。新聊天、语音和文档等操作会等待此前的设置保存完成。

预算调整不会清零当天已用、在途或未知调用。调低至已用额度以下会阻止后续超额请求；前台保留额度不能高于日额度。安静时段支持跨午夜，开始与结束相同时表示不按时段静音；每日主动上限设为0可停止主动消息。排队主动通知仍会按新策略复核。

音量范围0–100，默认100；100直接播放原文件，低于100时缩放下一次播放的PCM WAV临时副本，不修改原音频或系统音量。0表示静音。尚未保存的音量输入不会影响播放。当前非PCM音频不支持副本音量处理，失败会明确提示，不以原音量继续播放。停止或关闭播放会清理临时副本，真实声卡仍需单独实测。

设置文件损坏，或运行中被删除、外部替换时，保留原件并停止覆盖，显示只读提示；本地聊天仍可使用。启动前文件已不存在时会按首次配置使用默认值。先备份数据并修复/恢复该文件，再重启，不要用空默认文件覆盖现场。

## 等待、取消与退出

普通聊天发送后显示等待秒数和“取消等待”；窗口仍可切页、滚动和操作设置。取消后旧回复不会覆盖新请求，也不会自动朗读；已经发给供应商的请求仍计入额度，不能保证撤回远端执行。API连接探测继续区分“已配置”“已开启”“本次探测成功”，配置存在不等于接口已连通。

关闭主窗口就是退出，不会转为后台托盘运行。窗口会先取消等待、保存数据，再等待外部线程与播放收尾；保存失败会明确提示。再次启动从已保存的数据恢复，短期对话不作为完整历史档案恢复。

## 数据位置与导出

设置页显示实际数据根、持久数据、分享目录、输出目录、桌面设置和逻辑导出目录。“导出”产生 `<home>/output/exports/` 下的独立JSON，包含当前有效记忆、公开活动/学习视图、设置、预算元数据及明确标为本次会话的近期对话。

逻辑导出供用户查阅，**不能代替完整恢复备份**。不递归拷贝数据根，不包含`.env`、供应商凭据、学习私有评分依据或任意原始文件。导出期间来源撤销或退出，不会发布旧快照。已经导出的副本、旧备份和分享归档须由用户另行管理，后续遗忘不会自动擦除它们。

## REPL入口

```text
/desk today
/desk find 周末
/desk settings
/desk set quiet_start 21
/desk set daily_calls 20
/desk set volume 60
/desk set model "自己的模型名"
/desk export
```

`/api on|off`、`/net on|off`、`/model 供应商`、`/voice 音色` 也使用相同的持久设置入口。字段类型、预算及查询长度不合法会报告错误，不自动发送模型请求。

本地桌面验收采用真实Tk控件、临时数据与假SDK；人工易用性、真实供应商质量、真实声卡及7天使用仍由后续验收记录。
