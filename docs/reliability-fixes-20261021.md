## API 使用

双击根目录 `start_gui.bat`。进入“设置”，供应商选 **DeepSeek**，模型选 **deepseek-flash**，点击 **应用模型**，打开 **API**，再点击 **测试连接**。若旧保存模型不可用，测试结果会显示具体模型和可执行的修改提示。更新保持现有桌面选择，不静默切换供应商或开启后台调用。

未安装 `openai` / `python-dotenv` 时仍使用内置 HTTP / 配置读取器，**不用再次执行 `pip install -e .`**。其它供应商、MiMo 语音及人工长期使用的验证边界仍以各自原报告为准。
