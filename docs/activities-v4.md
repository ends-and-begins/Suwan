# 第四版使用与数据说明

状态页增加活动列表。选中活动可查看开始原因、预期产物、完成条件、当前步骤和错误说明。已完成作品仍在作品页查看。

## 暂停、继续与未知

- “暂停活动”阻止主动活动继续推进，不影响用户聊天，也不等于关闭全部 API。已被供应商接收的请求不能撤回；返回的有效草稿可以保存，后续步骤暂停。
- “恢复活动”解除整体暂停。“继续所选”也会解除整体暂停，并优先推进指定的未完成活动，从已保存阶段接续。
- “结果未知”意味着请求可能已被供应商执行，不能自动再发。取消该未完成活动可以解除等待，但不会退回已分配调用额度。之后的新活动拥有新 ID，不冒充旧请求的恢复结果。
- 已完成活动可喜欢/不喜欢。每个活动只有一票，重复点击覆盖上一票；同类选择权重最多上下调整 10%，仅在近期 24 小时内生效，不改写长期兴趣。
- 日历行只供查看：日记和故事按日期占位，失败、暂停、未知当天不自动重发；次日处理新日期。

REPL 命令：`/activities`、`/pause`、`/resume`、`/continue ID`、`/discard ID`。取消入口处理未完成活动，不能通过它删除已完成作品。

## 调用与主动消息设置

可在现有环境配置中增加下列变量。未填写时采用默认值；非法数值拒绝启动，避免悄悄使用更宽松的额度。修改后重新启动。

| 变量 | 默认值 | 含义 |
|---|---:|---|
| `SUWAN_DAILY_CALLS` | 40 | 所有外部生成和语音共用的每日调用上限 |
| `SUWAN_DAILY_OUTPUT_TOKENS` | 32768 | 每日文本请求 `max_tokens` 的累计预留上限 |
| `SUWAN_FOREGROUND_RESERVED_CALLS` | 4 | 后台不能使用的前台调用额度 |
| `SUWAN_FOREGROUND_RESERVED_OUTPUT_TOKENS` | 4096 | 后台不能使用的前台文本输出额度 |
| `SUWAN_PROACTIVE_DAILY_LIMIT` | 8 | 每日本地主动消息认领上限，可设 0 |
| `SUWAN_QUIET_START` | 22 | 安静时段开始小时，含该小时 |
| `SUWAN_QUIET_END` | 8 | 安静时段结束小时，不含该小时 |

前台保留量不能大于总量；如将日调用设为 0，也须将前台调用保留设为 0。安静时段首尾相同表示不设时段禁令，主动日上限与原有联系偏好仍生效。

聊天、文档、日记、故事、活动、独白和语音排在同一执行队列。排队的前台请求先于后台；已经发送的请求继续占用执行槽，取消等待不提前释放它。独白的本地节拍保留，默认模型独白尝试间隔为1小时，冷却通过最近100条调用记录跨重启延续。默认日额度下记录足以覆盖该间隔；若自行大幅提高额度、在一小时内产生超过100条调用，旧冷却记录可能被挤出视图，总调用预算仍有效。

“文本输出预留”不是实际 token，也不是总 token 或费用上限。发送过的请求即使失败、被取消或实际返回很短，仍占用原预留；只有可以确认未发送才释放。供应商返回的实际用量单独显示，未返回则未知。语音接口未提供可强制执行的输出 token 上限，只纳入调用数。输入 token、语音实际成本和供应商计费请另行核对。

日额度按发送时的本地日期归属，旧日期未知账目继续保留。预算耗尽时后台暂停；本地聊天仍可使用。安静时段仅控制主动展示，内部活动与用户主动请求分别处理。通知先持久认领再发布，极端崩溃可能少显示一条，但不会靠重启补发一批旧消息。

## 文件与恢复

新文件位于当前数据目录 `<home>/v2`：

- `activity-v4.json`：活动步骤、生成草稿、来源指纹、产物路径与完成收据。
- `call_ledger.json`：调用元数据、预留、实际用量、耗时与未知状态；不含提示词、正文和密钥。
- `notification-v4.json`：主动消息日期与认领 ID；不含正文。
- `calendar-v4.json`、`calendar-artifacts/`：日期占位与日记/故事产物。原 `diary.txt`、`story.txt` 继续作为兼容导出。

日记、故事默认在本地 21 点后的首次节拍各处理当天一次。重启不会逐日补离线期间的内容；已有当天旧格式文本会被识别为已完成。

遗忘或纠正来源会撤销相关活动、清除草稿，并清理该活动登记且内容摘要匹配的内部作品。路径处已有不同内容时保留文件并报告清理失败。备份、已导出日记/故事及归档仍须单独清理，日历产物也属于这组导出记录，不用于自动恢复用户事实。

损坏或运行中被外部改动的账本会保留原件并进入写保护。调用/通知账本不可用时分别暂停外部生成/主动展示；核心活动、日历记录无法安全恢复时可能拒绝启动。先保留整个数据目录，再从有效备份恢复，重新启动验证。不要删除账本来重置额度；也不要用旧代码直接打开已经升级的新数据目录。需要回退时恢复对应版本完整备份到独立目录。

## 本轮边界

成果检查涵盖非空正文、持久化、来源有效性、收据和去重。学习笔记仍是模型解释或本地内容，可能有错误，不能据此声称已掌握知识；内容核验与后续应用留给下一阶段。虚拟时钟的 24 小时模拟不等于真实机器连续运行 24 小时，真实供应商质量与费用、声卡及长期体验另行验证。
