# 苏晚第七版源码候选包使用说明

本包是需要 Python 和运行依赖的源码候选版，保留七个桌面页签。它用于本机试用与验收；真实供应商、声卡、人工易用性、24小时连续运行及7天实际使用均须分别记录结果。短时测试通过不代表长期验收完成。

## 安装与启动

项目声明需要 Python 3.12 或更新版本；本轮自动验收使用 Windows、Python 3.14.7及本机已有依赖。没有验证全新Windows或全新解释器的依赖安装，也没有把依赖或Python解释器打进ZIP。

将候选ZIP解压到自己的可写目录。在该目录打开PowerShell，按包内pyproject.toml安装运行依赖，然后启动：

```powershell
python --version
python -m pip install .
python start_suwan.py --frontend gui --home "$env:LOCALAPPDATA\Suwan\home"
```

双击start_gui.bat或start_repl.bat会使用当前用户的LOCALAPPDATA下Suwan/home目录；需要其他数据位置时，使用start_suwan.py显式传入--home。代码保留旧版兼容默认值，候选包启动器会明确传递所选目录。

本地离线对话示例：

```powershell
python start_suwan.py --frontend repl --home ".\my-suwan-home" --offline
```

启动器跳过隐式dotenv读取；包内没有旧密钥或个人数据。供应商凭据需由用户自行配置环境变量，API与联网首次默认关闭。已有桌面设置会恢复；离线启动会阻止真实网络访问。具体模型能否使用、供应商连接和语音设备需要独立实测。

## 日常操作

对话页可打开今日回顾，按关键词或类型查看当前有效经历、活动和学习来源。作品概览按完整有效登记计数。记忆页可搜索、更正、遗忘和暂停记录；已撤销来源的派生结果不会作为当前知识继续使用。

设置页显示当前生效数值及未保存草稿。保存模型、音色等选项不会覆盖正在编辑的数值；较早回执也不会覆盖后来的输入。切换供应商时会撤销旧供应商的模型草稿。预算保留已用、在途和未知账目，主动消息上限与安静时段控制展示。

等待聊天时可取消，迟到回复不会覆盖新对话；已发送的远端调用不能靠取消收回额度。关闭主窗口会退出程序，并等待保存与工作线程收尾。近期对话属于本次会话，不承诺完整全文长期恢复。

## 备份、恢复与回退

完整恢复需要数据目录的停机副本及相应代码版本。先正常关闭程序，确认保存与进程退出完成，再将整个--home目录复制到一个新的备份目录；保留全部子目录和文件。不要只复制某一个JSON，也不要用逻辑导出代替恢复备份。

恢复时保留出错目录原件，将备份复制到另一个空目录，再用相应代码版本和显式--home打开恢复副本。升级前先保存代码和数据；回退使用旧代码配套的升级前数据副本，避免旧代码直接写入更新格式的数据。

备份和逻辑导出包含的用户副本由用户管理。应用中的遗忘会撤销当前有效来源及关联内容，不能自动擦除此前的导出、历史备份或分享归档。候选ZIP不包含开发备份、研究日志或个人运行数据。

可用PowerShell核对候选ZIP与交付报告的SHA-256是否一致：

```powershell
Get-FileHash -Algorithm SHA256 .\suwan-v7-candidate.zip
```

包内manifest.json给出每个文件的长度与SHA-256；scripts/release_round7.py提供完整校验与安全解包函数。这是完整性核对，不是发布者数字签名。

## 真实时长观测

观测工具使用新的合成数据目录，API和联网关闭，不读取已有个人home。数据目录与报告目录必须都不存在、彼此不包含；每次新run使用新的目录，不拼接上次运行秒数。

```powershell
python scripts/observe_round7.py --home ".\probe-home-new" --output-dir ".\probe-report-new" --duration-seconds 86400 --interval-seconds 60
```

报告写在home之外，记录真实经过时间、采样间隔、任务/线程/队列数量、预算、文件增长及可取得的进程内存。只记录计数和状态，不记录聊天正文、请求内容或密钥；队列高水位是采样所见值。

heartbeat.json表示最近采样时的状态；进程已退出时，旧文件中的RUNNING不能证明仍在运行。summary.json是收尾结果。短时run即使PASS，也不表示24小时通过；只有单次真实时长达到86400秒、连续样本合格、核心持续存活且真实时钟事件持续推进、无已知组件错误并正常退出后，24h_verified才可为true。进程中断、异常或超过阈值的采样空档（例如长时间休眠）不能算通过；连续采样阈值为max(1秒,3×采样间隔)。核心时钟推进另有健康期限，恢复后也保留超限记录；短暂休眠不一定超过这些阈值。最短请求可能延长至首个真实时钟事件或健康期限，不会快进时钟。没有最终summary不能算PASS。

需要提前停止时，在本次报告目录创建STOP文件：

```powershell
New-Item ".\probe-report-new\STOP" -ItemType File
```

提前停止长目标会保留实际时长并标为INCOMPLETE，不会补填通过。本工具的离线观测不验证真实模型效果、真实网络或真实声卡。

## 七天实际使用

seven-day-log.json包含7个空白日，初始状态均为PENDING。复制一份到自己的记录目录，逐日填写实际日期、使用时段、召回正确/漏记/记错、纠错遗忘、主动打扰、学习复用、故障恢复、调用已知/未知量和证据位置。未使用的日期不算完成一天，不提前填写成功结果。

真实学习8/10正确及至少5组有效改善、自然度和人工易用性仍需专门资料与实际评阅。源码候选包和自动化任务通过只说明所验证的本地流程。
