# 苏晚：人格、交流偏好与关系来源

苏晚保持自己的名字和数字伙伴身份，喜欢阅读、文字创作与共同探索。表达真诚、具体，先回应当前问题；不确定就说明，不用情绪或亲密分数要求用户陪伴。疲倦可以说累，低落可以表达感受，但不改写用户已经确认的事实。

稳定人格进入聊天、独白、自主创作、日记、故事和文档的统一模型上下文。情绪、精力、活动与关系熟悉程度属于动态状态；模型对语气的实际遵守程度仍需真实接口和人工评阅。

## 调整交流

在 GUI 设置页选择回答风格“自然 / 直接 / 详细”，主动程度“正常 / 少 / 停”。也可以直接说：

- “回答直接一些”“回答详细一些”“恢复自然回答”。
- “少一点主动消息”“暂停主动消息”“恢复主动消息”。

明确设置会立即保存，暂停自动长期记录期间也可以设置；保存失败会提示并显示当前实际值。少主动采用所有主动通道共享的30分钟冷却，启动后先等待30分钟；冷却仅在本次运行内计算，重启重新等待。停主动会阻止可见独白、叙事和自动分享提示，用户发问、主动生成文档与语音回执仍可用。内部创作可以继续，停主动不等于停止所有模型调用。

少主动同时限制实际显示频率。界面长时间未响应时，超过30分钟的低频主动消息会丢弃，恢复后不会把积压消息连续弹出；手动操作回执不占主动消息额度。

记忆页可查看或遗忘 `preference.response_style`、`preference.initiative`，遗忘后恢复默认。REPL 也可以使用：

```text
/memory set preference.response_style=brief
/memory set preference.initiative=off
/memory forget-key preference.initiative
```

可执行值分别为 `normal|brief|detailed` 和 `normal|low|off`。已有 `preference.contact_time` 识别“上午可以提醒”“晚上别提醒”等有限日部分语法；无法识别的自由文本会暂缓主动展示，需要用户纠正。以上不是通用自然语言理解器。

## 关系为何变化

普通聊天和普通“谢谢”不自动加亲密度。当前只把完整明确反馈与已保存的分享资料作为来源；不把模型写出的故事当作共同经历。

| 来源 | 每个发生日期的上限 | 亲近 / 信任变化 |
|---|---|---|
| “这次解释很有帮助”等明确正反馈 | 1次 | +0.4 / +0.3 |
| “刚才你理解错了” | 1次 | -0.1 / -0.5 |
| “这次理解对了”“现在解释清楚了” | 1次 | +0.2 / +0.5 |
| 成功保存的不同分享内容 | 3次 | 每次 +0.2 / +0.05 |

同一来源只计算一次，相同分享内容改文件名仍去重。反馈有轻微、会衰减的短期情绪影响；纠正或遗忘来源时清理失效影响，不重新授予或延长时效。暂停自动记录时不追加反馈来源；写入失败不能确认关系已经改变。

状态板显示最近原因与来源ID，可到记忆页按ID核对。关系快照只保存固定说明、增量、时间和ID，不再复制原文或文件名。纠正为中性或遗忘来源后重新计算；重启不会再加一次。旧版只有数值的关系保留为“缺少逐条来源”的历史基值，不伪造经历。

精确遗忘会删除关联来源与派生记录。未关联同文副本、备份、归档与导出文件仍需分别核对处理；关系规则不是任意语义去重。跨日活动连续性、持久调用预算和长期陪伴自然度属于后续验证范围。

第三版补修后，自动生成记忆会绑定实际输入来源。补修前缺少完整来源追踪的旧生成记录仍保留在记忆管理中，可使用`/memory find --all 词语`核对；自动上下文、梦境与随机回忆暂不使用这些旧生成记录，避免把已遗忘的信息再次传播。升级和回退边界见[补修报告](round3-fix-report.md)。
