## 历史生成内容与兼容

第三版以前自动生成的内容可能漏记真实依赖，无法从正文可靠推断原来源。本轮采取保守隔离：保留这些记录供记忆管理查看/删除，自动上下文、梦境片段及随机回忆不再使用缺少完整来源追踪标记的旧生成记录；没有伪造依赖或删除原文。修补后生成的内容使用已有source_ref字段携带来源追踪版本，依赖仍通过derived_from保存，能够复用并级联撤销。

记忆信封仍为version 2。关系快照仍为version 3，增加可选`baseline_sources`边界，严格接受此前已发布的v3结构。此前已经被旧第三版重复加过分的历史快照无法自动判断哪些旧分应扣回，本轮保留其已有基值，不静默猜测重写；本轮防止从旧两数值格式首次升级时再重复。

新关系快照增加的字段不被旧第三版读取器接受。若要回退旧程序，请恢复相应完整备份到独立目录，不要直接用旧代码打开升级后的数据目录。

旧两数值关系只作为缺少逐条经历的历史基值；迁移时存在且已落盘的旧分享统一视为迁移前来源，不再授予新的分享增量。导出作品、日记、归档和完整备份仍需用户单独核对清理。

## 实际限制

- 搜索和模型已进入外部发送的请求无法物理撤回；尚未发送的排队请求会撤销，迟到结果不提交。真实供应商、联网服务、TTS与声卡未实测。
- 关系首次冷计算或新大分享的第一次散列仍同步执行一次；已修复的是无变更时周期性重复全文处理，不宣称冷加载已完全异步。
- 低频展示冷却只在当前GUI运行内，旧消息超过30分钟丢弃；不是跨重启的持久调用预算。安静模式仍允许内部生成和用户主动请求。
- 生成依赖按实际输入来源保守绑定，不推断模型具体使用了哪一段；状态文本限长仍保留参与构造的状态来源，可能导致纠正一个输入后同时清理多份相关生成记忆。
- 人工自然度、真实模型质量、长期连续运行和第四版能力仍另行验证。
