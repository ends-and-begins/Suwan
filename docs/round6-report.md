## 完成的桌面流程

| 位置 | 当前行为 |
|---|---|
| 对话页 | 顶部今日概览，集中显示活动、待办、经历与当前可访问作品；打开回顾或跳转原作品集页 |
| 今日回顾 | 关键词和类型筛选，查看记忆、活动与学习公开记录的正文、来源及保存状态；来源撤销后刷新当前视图 |
| 设置页 | 可滚动；模型、API/联网、音色、自动朗读、音量、预算与安静时段先保存再应用，重启恢复 |
| 等待与取消 | 显示等待秒数；窗口仍可操作，取消后旧回复和自动朗读不再覆盖当前对话，已发送额度保留 |
| 数据入口 | 显示实际目录和各类内容保留范围，显式导出当前逻辑JSON快照 |
| REPL | `/desk today`、`find`、`settings`、`set`、`export` 使用相同运行时入口 |

保留原七个页签及既有记忆管理、作品预览和故事入口。新增桌面快照与设置命令由运行时所属事件循环处理；前端用上下文版本及请求序号拒绝过期回执。没有将旧作品集、故事文件浏览改成完整历史索引。

桌面设置使用独立版本文件和严格字段校验。损坏、运行中删除或外部替换时停止覆盖并提示；启动前文件已不存在时使用默认值。预算调整保留已用、在途与未知账目，降低主动上限会重新约束排队通知；手动回执保持有效。

作品概览只计当前来源有效、登记路径合法、文件存在且长度/摘要匹配的创作产物。逻辑导出采用固定公开对象范围，先后台写临时文件，回运行时确认上下文仍有效后发布；取消、遗忘或退出会清理未发布文件。它不递归复制数据根，不包含密钥或学习私有评分依据，不能用作完整恢复备份。

音量100沿用原文件播放；0–99对PCM WAV生成临时副本，支持8/16/24/32位采样，不改原文件和系统音量。未保存的设置不影响播放；取消期间迟到的转换不会启动声音，停止后清理副本。
