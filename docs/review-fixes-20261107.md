## 修改后的行为

1. **记忆读写及 GUI 状态。** 同一个记忆对象的读取、加载、事务与提交使用可重入锁；文件替换和摘要交接期间，状态工作线程等待操作完成。GUI 状态展示读取独立发布的元数据，不访问磁盘、不改变记忆状态，也不等待保存锁。元数据只在最外层操作提交或回滚后发布。显式 reload 的完整上下文通知在释放记忆锁后执行，避免与状态保存锁顺序相反；真实外部删除和等长改写的保护仍保留。
2. **设置冲突。** 提交认领实际旧对象、比较已加载摘要并以不覆盖方式发布。同名外部新文件保留。程序重启时如果发现主文件缺失、旧文件已被认领，会进入写保护并显示恢复位置。
3. **关系重建成本。** 一次计算取得校验后的独立快照，包含记录副本、持久收据集合和只读正文版本映射。循环内不再逐条触发整库校验。300 条、1,391,438 字节的相同合成资料，整库校验从 602 次降至 2 次，累计散列从 837,645,676 字节降至 2,782,876 字节；新增普通消息后仍为 2 次。该数据是逻辑散列量，不等于物理磁盘读取量。
4. **文档失败隔离。** 文档服务将等待超时、输出写入失败转换为带安全类别的 DocumentGenerationError；命令行显示原因后继续接受下一条命令。原始接口及磁盘异常细节不进入提示，取消仍按 CancelledError 传播。GUI 继续沿用已有失败回调处理该错误。
