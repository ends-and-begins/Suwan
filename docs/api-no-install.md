# API 免新增安装修复（2026-10-20）

2026-10-21 追加边界补修：原生 HTTP 和 SDK 均拒绝无法编码为 UTF-8 的回复；连接测试对旧 DeepSeek 模型不可用给出具体修改提示；慢日志不再占用撤销操作和状态文件的锁。详情见 [本轮可靠性补修](reliability-fixes-20261021.md)。

## 怎么启动

在项目根目录双击 `start_gui.bat`。本轮启动和 DeepSeek 聊天不需要执行 `pip install`。

在聊天页点“连接设置”，在“模型连接”中选择 **DeepSeek** 和 **deepseek-flash**，点击“应用模型”。勾选 **启用模型 API**，再点 **测试连接**。连接结果会显示在该卡片内和窗口底部。“网页搜索”可以保持关闭。
已有桌面设置会继续保留此前选择的模型；升级不会静默改写用户设置。

## 这次解决了什么

1. `python-dotenv` 缺失时，内置标准库读取器仍能读取项目根 `.env`；保持显式路径优先、文件覆盖环境值、离线模式禁止读取等规则。
2. `openai` SDK 缺失时，通过 Python 标准库发送一次 HTTP 请求，不要求安装额外包。已安装且能导入 SDK 的环境继续使用 SDK。
3. 连接测试区分密钥、余额、模型、限流、超时、证书、网络和本地预算问题；不把供应商原始错误正文或密钥写进界面。
4. 请求继续经过原有调用预算、排队、隐私代数和取消检查；不增加自动重试。HTTP 后备拒绝重定向、校验 TLS，并限制响应大小。
5. DeepSeek 下拉列表增加 `deepseek-flash`、`deepseek-v4-pro`，未指定模型的新配置默认采用 `deepseek-flash`。这两个模型的交互请求关闭默认思考，让短输出额度用于实际回复；已有桌面模型选择、显式环境变量和其他供应商不自动改动。

内置配置读取器支持 UTF-8/BOM、单行键值、引号、注释、`export`、`${NAME}` 和 `${NAME:-default}`；它不执行 shell 语法，也不支持多行引用值。文件格式错误时只报告行号，不展示值。
