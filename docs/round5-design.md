# 第五版：有来源、可核对和可复用的学习

设计日期：2026-10-19。对应迭代计划阶段4。起点为第四版严格审查补修后的592项离线测试。修改前完整备份 `rf-pre-round5_20261019-115839`：1026文件、4,860,216字节，SHA-256零差异与空目录恢复校验通过。

## 本轮闭环

第一轮限定学习用户明确提供的文本。原记忆仍拥有用户/分享原始资料，新学习存储分别保存任务、笔记、核对结果及来源引用，不把模型解释重新当成用户事实。

任务按“资料隔离的学习前测试 → 阅读与笔记 → 独立检查 → 预留应用”推进，每步持久化。问题、标准答案及评分依据在生成前确定。标准答案只给评分器，不能传入生成提示；预留应用问题只在检查作答提交后公开。学习前测试不读资料、历史对话、已有笔记或统一状态上下文。

答案使用明确JSON契约，独立核对状态、答案的值和类型、引用是否存在于当前资料，并检查预先要求的依据。模型自述“答对了”不能授权完成。笔记默认待核实；通过任务检查只称“与本任务资料及评分约定一致”，不保证现实普遍正确。

## 恢复、隐私与调用

- 复用共享调用队列、预算和适配器撤销代数；每个阶段稳定调用键，先保存意图再发送。未知请求不自动重发，关闭API不拿本地标准答案冒充生成结果。
- 原资料ID与内容指纹同时校验；更正、遗忘、暂停和退出覆盖待发送请求与迟到回调。源失效后清理内部题目、笔记、回答、评分答案及版本正文，停止提供旧知识，重启不得复活。
- 学习文件严格结构校验、原子提交及运行中改动保护。任务与知识两个逻辑集合放同一存储包，避免多文件半提交。
- 任务目标由当前有效的检查、应用证据投影为两个里程碑；旧活动次数保留为历史，不再用生成笔记次数表示新知识掌握。
- 笔记修订登记前版、修改理由和内容摘要；保留原学习前测试。预留题已经见过的后续复测单列，不能继续计入首次留出改善率。

## 使用与复用

保持七个页签，使用状态页和 `/learn` 命令登记任务、逐步或连续执行、查看、取消、修订及检索。来源为已有记忆ID，可来自用户显式管理或分享资料。任务JSON由用户提供问题与评分依据；本轮不自动读取任意网页或后台下载资料。

有效知识可进入后续聊天上下文，携带来源ID和资料引用。冲突条目保持有分歧状态，不挑一条冒充确定事实。没有模型时可查资料与状态，不能宣称通过了模型学习检查。
