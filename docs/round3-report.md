## 交叉审查中补齐的边界

1. 合法长来源ID与历史挤占提示词：状态展示限长，优先给完整当前输入留空间，不在末尾整体截断问题。
2. 同ID正反馈纠正为负反馈：清除方向失效的情绪，不重新授予或延长短期影响。
3. 遗忘已提交、会话快照保存失败后退出：启动时按当前记忆再次清理情绪，旧快照不能复活被遗忘来源。
4. 生成通知与真正发布之间发生遗忘：保留正文来源代数与构造时间，在异步等待后和队列各边界复核，旧内容不能重新取得新授权，也不能回填短期历史。覆盖社交、回忆、独白、分享与安静模式下的内部独白。
5. 自动入睡/醒来toast原先绕过主动限制：现在也使用共享策略，真实节律器官与GUI桥的安静/低频回归通过。

反馈来源使用原子记忆事务：写失败回滚，不能确认关系改变；次级快照失败会明确提示，已提交的来源仍是重启后重新计算关系的依据。已有来源的衰减情绪只校验清理，不在重启时补发一次。
