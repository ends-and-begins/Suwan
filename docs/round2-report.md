## 实现结果

- 记忆升级为版本化格式，具有稳定 ID、内容类型、来源、时间、主题和派生关系；旧列表保留原字节副本，不猜成用户事实。
- 确认事实以记忆文件为权威，支持姓名、城市和三类偏好的有限语法更新；旧修订退出活动检索，重启保持新值。
- 对话采用确定性本地检索，向模型注明记录 ID、类型和来源。用户原话与模型回复分开，分享保留完整正文及原文件归档，生成文字不能充当确认事实。
- 新增图形记忆页与 `/memory` 命令，支持查看、搜索、补充、设置、纠正、遗忘与暂停。使用方法及格式见 [memory-v2.md](memory-v2.md)。
- 遗忘同步移除活动正文、修订及派生后代，保留最小去重账目，清理会话/独白缓存，拒绝后台迟到和总线排队的过期提交。旧姓名快照、旧迁移标记失败重试不能复活姓名。

## 验证中发现并修复的问题

1. 暂停状态的服务接口错配：统一读取持久化记录开关，暂停时停止自动记忆生产和分享消费。
2. 更新事实引用被替代事实时可能误删新值：更新前拒绝这类依赖，导入及加载也不能接受活动记录引用已替代来源。
3. 仅检查模型返回时机不足以阻止旧结果：总线接收端也验证提交代数，聊天等待记忆回执后再次核对，分享撤销时保留原件。
4. 旧事件可能在清缓存后才被消费：感官按清理水位拒绝旧事件，聊天在取得串行锁和感官回执后检查上下文是否仍有效。
5. 无问号反问、推测或举例可能被当姓名：收紧有限语法；迟到的文档同样拒绝导出。
6. 记忆已提交而快照失败：保留明确警告，启动从事实投影姓名，并丢弃无来源的旧独白缓存。

既有演练作必要适配：JSON 裸列表断言改为版本化 `items`；持久化测试采用明确“我叫”语法；阻塞 SDK 场景使用普通聊天触发模型，保留原关闭和保存断言。另修复销毁窗口后读取页数、多 Tk 测试对象在错误线程回收的问题。未以删除失败场景或修改冻结问句换取通过。

## 限制与下一步

这轮完成的是本地记忆闭环。检索为小型规则词表与词法匹配，事实抽取为有限完整句式；没有通用中文理解、自动事实核验或向量检索承诺。分享原文没有独立分块索引；大规模记忆性能尚未验证。真实 LLM、搜索、TTS、声卡、人工自然度与长期运行均未验证。
